Verified feature

검사 체크리스트

재사용 가능한 계획과 템플릿으로 작업을 표준화합니다.

The problem it solves: 방문마다 다른 검사를 사용하면 반복 검사를 비교하기 어렵습니다.

What you can do

  • 재사용 가능한 검사 계획 생성
  • 템플릿과 검사 지점 선택
  • 검사를 재개하고 실행 이력 확인

Available options

  • 템플릿, 전송, 빈도와 기본 시간

Supported inputs

  • 항목, 계획 이름, 위치와 일정

Outputs

  • 진행률이 표시된 반복 검사 작업

Workflow

  1. 계획 생성 또는 선택
  2. 템플릿과 전송 설정 선택
  3. 검사를 실행하고 각 지점 완료

Limitations

  • 알림은 검사를 자동으로 시작하지 않습니다.
