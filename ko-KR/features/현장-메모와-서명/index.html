사용 가능한 기능

  • 결과와 권고 사항 기록
  • 서명 프로필 관리
  • 메모와 서명을 보고서에 포함

설정 항목

  • 검사자, 안전 담당자와 감독자 서명 정보

필요한 정보

  • 메모, 문제, 권고 사항과 서명 정보

결과

  • 승인 정보가 포함된 검사 기록

작업 흐름

  1. 항목 열기
  2. 발견 사항 기록
  3. 보고서 전에 서명 정보 추가

제한 사항

  • 항목은 선택한 보고서 템플릿에 따라 달라집니다.
