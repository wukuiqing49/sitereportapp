Verified feature

사진과 위치 기록

가능한 경우 사진을 항목에 연결하고 메모, 시간, 위치를 기록합니다.

The problem it solves: 검사 맥락이 없는 사진은 나중에 증거로 활용하기 어렵습니다.

What you can do

  • 한 장 이상 사진 촬영
  • 검사 기록에 사진 연결
  • 가능한 경우 위치와 촬영 시간 기록

Available options

  • 사진 출처, 검사 항목과 표시 주석

Supported inputs

  • 사진, 메모와 위치 권한

Outputs

  • 정리된 사진 증거

Workflow

  1. 검사 항목 열기
  2. 증거 사진 촬영 또는 선택
  3. 사진 확인 후 계속

Limitations

  • 위치 정보는 기기와 권한 상태에 따라 달라집니다.

Common questions

사진을 검사 항목에 연결할 수 있나요?

예. 현재 검사 기록과 항목에 증거를 연결합니다.
