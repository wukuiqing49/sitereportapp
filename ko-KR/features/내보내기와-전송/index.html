Verified feature

내보내기와 전송

파일을 내보내고 설정한 서버로 전송합니다.

The problem it solves: 완료된 보고서는 고객과 공유하거나 프로젝트 저장소로 보내야 하는 경우가 많습니다.

What you can do

  • PDF, 이미지와 ZIP 내보내기
  • 기기에서 파일 공유
  • 설정한 프로토콜로 전송

Available options

  • 형식, 서명, 프로토콜, 서버와 경로

Supported inputs

  • 생성된 파일과 전송 프로필

Outputs

  • 공유 가능한 파일 또는 전송 결과

Workflow

  1. 보고서와 파일 선택
  2. 공유 또는 전송 선택
  3. 상태 확인 또는 패키지 공유

Limitations

  • 전송에는 설정된 대상과 네트워크 연결이 필요합니다.

Common questions

어떤 서버 프로토콜을 지원하나요?

FTP, FTPS, SFTP, WebDAV와 SMB/NAS 설정을 지원합니다.
