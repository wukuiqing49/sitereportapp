Verified feature

PDF 보고서

검사 데이터에서 구조화된 현장 보고서를 생성합니다.

The problem it solves: 현장 관찰 내용을 일관된 보고서로 만들려면 수동 서식 작업이 필요할 수 있습니다.

What you can do

  • PDF 현장 보고서 생성
  • 결과, 사진, 위치, 메모와 서명 포함
  • 생성된 파일 확인

Available options

  • 템플릿, 스타일, 형식과 서명

Supported inputs

  • 프로젝트 정보, 결과, 사진과 메모

Outputs

  • PDF 보고서와 내보내기 파일

Workflow

  1. 검사 기록 완료
  2. 보고서 옵션 선택
  3. 파일 생성 및 확인

Limitations

  • 일부 스타일은 에디션 또는 이용 플랜에 따라 달라집니다.

Common questions

보고서에 무엇을 포함할 수 있나요?

프로젝트 정보, 검사 결과, 사진, 위치, 시간, 메모와 서명을 포함할 수 있습니다.
