Verified feature

검사 프로젝트

현장 정보, 진행률, 사진과 보고서를 한곳에서 관리합니다.

The problem it solves: 프로젝트 정보, 사진과 보고서가 흩어져 있으면 현장 기록을 추적하기 어렵습니다.

What you can do

  • 검사 프로젝트 생성 및 관리
  • 상태와 진행률 확인
  • 프로젝트 사진과 보고서 보관

Available options

  • 프로젝트 상태와 설명

Supported inputs

  • 이름, 위치, 고객 정보와 메모

Outputs

  • 진행률과 이력이 포함된 프로젝트 기록

Workflow

  1. 프로젝트 생성
  2. 현장 정보 입력
  3. 검사를 실행하고 진행률 확인

Limitations

  • 사용 가능한 항목은 설치된 버전에 따라 달라집니다.

Common questions

프로젝트에 보고서를 저장할 수 있나요?

프로젝트 흐름에는 정보, 진행률, 사진과 생성된 보고서가 포함됩니다.
