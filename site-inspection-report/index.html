Common questions

What can a SiteReport inspection report contain?

Depending on the workflow and available device data, a report can include project information, checklist results, photos, location records, time records, notes, and signatures.

Can I share a site inspection report?

Yes. The app supports previewing and sharing generated report files, with additional server delivery available when configured.
