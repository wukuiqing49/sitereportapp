Verified feature

Exportación y entrega

Exporta archivos y envíalos a un servidor configurado.

The problem it solves: Los informes terminados suelen necesitar compartirlos o enviarlos al almacenamiento del proyecto.

What you can do

  • Exportar PDF, imágenes y ZIP
  • Compartir archivos desde el dispositivo
  • Enviar mediante protocolos configurados

Available options

  • Formato, firmas, protocolo, servidor y ruta

Supported inputs

  • Archivos generados y perfil de entrega

Outputs

  • Archivos compartibles o resultado de carga

Workflow

  1. Genera y elige archivos
  2. Selecciona compartir o entregar
  3. Revisa el estado o comparte el paquete

Limitations

  • La entrega necesita un destino configurado y acceso de red.

Common questions

¿Qué protocolos admite?

El proyecto incluye FTP, FTPS, SFTP, WebDAV y SMB/NAS.
