Verified feature

検査プロジェクト

現場情報、進捗、写真、レポートをまとめて管理します。

The problem it solves: プロジェクト情報、写真、レポートが分散すると、現場記録を追跡しにくくなります。

What you can do

  • 検査プロジェクトを作成・管理
  • 状態と進捗を確認
  • プロジェクトの写真とレポートをまとめて保存

Available options

  • プロジェクトの状態と説明

Supported inputs

  • 名前、場所、顧客情報、メモ

Outputs

  • 進捗と履歴を含むプロジェクト記録

Workflow

  1. 新しいプロジェクトを作成
  2. 現場情報を入力
  3. 検査を実行して進捗を確認

Limitations

  • 利用できる項目はインストールされたバージョンによって異なります。

Common questions

プロジェクトにレポートを保存できますか？

プロジェクトフローには情報、進捗、写真、生成されたレポートが含まれます。
