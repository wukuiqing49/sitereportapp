Verified feature

出力と配信

ファイルを出力し、設定したサーバーへ送信します。

The problem it solves: 完成したレポートは、顧客や既存のプロジェクト保管先へ共有・送信する必要があります。

What you can do

  • PDF、画像、ZIPを出力
  • 端末からファイルを共有
  • 設定したプロトコルで送信

Available options

  • 形式、署名、プロトコル、サーバー、パス

Supported inputs

  • 生成ファイルと配信プロファイル

Outputs

  • 共有可能なファイルまたは送信結果

Workflow

  1. レポートとファイルを選択
  2. 共有または配信を選択
  3. 状態を確認またはパッケージを共有

Limitations

  • 配信には設定済みの宛先とネットワーク接続が必要です。

Common questions

対応するサーバープロトコルは？

FTP、FTPS、SFTP、WebDAV、SMB/NASの設定に対応しています。
