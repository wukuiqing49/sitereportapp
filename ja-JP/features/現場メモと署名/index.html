Verified feature

現場メモと署名

所見、推奨対応、署名情報を記録します。

The problem it solves: 所見や署名を別に記録すると、最終レポートから抜けることがあります。

What you can do

  • 結果と推奨対応を記録
  • 署名プロフィールを管理
  • メモと署名をレポートに含める

Available options

  • 検査員、安全担当、監督者の署名情報

Supported inputs

  • メモ、問題、推奨対応、署名情報

Outputs

  • 承認情報を含む検査記録

Workflow

  1. 対象項目を開く
  2. 所見を記録
  3. レポート前に署名情報を追加

Limitations

  • 項目は選択したレポートテンプレートによって異なります。

Common questions

署名はレポートに表示されますか？

署名プロフィールに対応し、生成されたレポートファイルに書き込みます。
