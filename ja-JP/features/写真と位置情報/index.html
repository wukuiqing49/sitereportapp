Verified feature

写真と位置情報

写真を項目に関連付け、可能な場合はメモ、時刻、位置を記録します。

The problem it solves: 検査の文脈がない写真は、後から証拠として使いにくくなります。

What you can do

  • 1枚または複数の写真を撮影
  • 記録に写真を関連付け
  • 利用できる場合は位置と撮影時刻を記録

Available options

  • 写真の入力元、検査項目、表示する注釈

Supported inputs

  • 写真、メモ、位置情報の権限

Outputs

  • 整理された写真証拠

Workflow

  1. 検査項目を開く
  2. 証拠写真を撮影または選択
  3. 写真を確認して続行

Limitations

  • 位置情報は端末と権限の状態に依存します。

Common questions

写真を検査項目に関連付けられますか？

はい、現在の検査記録と項目に証拠を関連付けます。
