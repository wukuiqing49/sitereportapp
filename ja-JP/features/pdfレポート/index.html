Verified feature

PDFレポート

検査データから構造化されたレポートを作成します。

The problem it solves: 現場の観察を一貫したレポートにするには、手作業の整形が必要になることがあります。

What you can do

  • PDF現場レポートを生成
  • 結果、写真、位置、メモ、署名を含める
  • 生成したファイルを確認

Available options

  • テンプレート、スタイル、形式、署名

Supported inputs

  • プロジェクト情報、結果、写真、メモ

Outputs

  • PDFレポートと出力ファイル

Workflow

  1. 検査記録を完了
  2. レポート設定を選択
  3. ファイルを生成して確認

Limitations

  • 一部のスタイルはエディションや利用プランに依存します。

Common questions

レポートには何を含められますか？

プロジェクト情報、確認結果、写真、位置、時刻、メモ、署名を含められます。
