Recurso do aplicativo

Projetos de inspeção

Reúna dados do local, progresso, fotos e relatórios.

Problema que resolve: Os registros ficam difíceis de acompanhar quando dados do projeto, fotos e relatórios ficam separados.

O que você pode fazer

  • Criar e gerenciar projetos de inspeção
  • Acompanhar status e progresso
  • Manter fotos e relatórios juntos

Opções disponíveis

  • Status e descrição do projeto

Dados necessários

  • Nome, localização, cliente e notas

Resultados

  • Registro organizado com progresso e histórico

Fluxo de trabalho

  1. Crie um projeto
  2. Informe os dados do local
  3. Execute inspeções e revise o progresso

Limitações

  • Os campos disponíveis dependem da versão instalada.

Perguntas frequentes

Um projeto pode guardar seus relatórios?

O fluxo do projeto reúne informações, progresso, fotos e relatórios gerados.
