Os registros ficam difíceis de acompanhar quando dados do projeto, fotos e relatórios ficam separados.

O que você pode fazer

  • Criar e gerenciar projetos de inspeção
  • Acompanhar status e progresso
  • Manter fotos e relatórios juntos

Procedimento

  1. Crie um projeto
  2. Informe os dados do local
  3. Execute inspeções e revise o progresso

Opções a revisar

  • Status e descrição do projeto

Limitações

  • Os campos disponíveis dependem da versão instalada.

Distinguir o projeto de cada visita

Identifique o local e a área no nome do projeto e registre o contexto do cliente. Em uma visita de retorno, confira o projeto existente para não dividir seu histórico. Antes de sair, compare o progresso com os registros, fotos e relatórios; o status do projeto, sozinho, não explica um problema pendente.
