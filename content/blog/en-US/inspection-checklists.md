# How to use Inspection checklist app in SiteReport

Repeated inspections are harder to compare when each field visit follows a different set of checks.

## What this feature helps you do

- Create reusable inspection plans
- Choose checklist templates and define inspection points
- Resume an in-progress inspection and review run history

## Where it fits in the workflow

- Create or select an inspection plan
- Choose the checklist template and delivery settings
- Run the inspection and complete each inspection point

## What to check before export

- Checklist template, delivery profile, frequency, and default time

## What to keep in mind

- A scheduled plan provides reminders; it does not start an inspection automatically.
