# How to use Inspection checklist app in SiteReport

Repeated inspections are harder to compare when each field visit follows a different set of checks.

## What this feature helps you do

- Create reusable inspection plans
- Choose checklist templates and define inspection points
- Resume an in-progress inspection and review run history

## Where it fits in the workflow

- Create or select an inspection plan
- Choose the checklist template and delivery settings
- Run the inspection and complete each inspection point

### Create or select an inspection plan

Start with the site and purpose of the visit. Create an inspection plan or select an existing plan for a repeat visit. Give it a name and location that distinguish it from other inspections. Reuse the same plan when visits need comparable results; review its inspection points when the scope changes.

### Choose the checklist template and delivery settings

Choose a checklist template that matches the work you need to inspect and review its inspection points before starting. Check the delivery profile, frequency, and default time if you use those options. A scheduled plan provides reminders, so the inspector still needs to start the inspection. Confirm the destination before using server delivery.

### Run the inspection and complete each inspection point

Start the inspection and work through its points. Record the result and relevant notes for each point, and attach photos where visual evidence is needed. If you leave an inspection unfinished, resume it and review its completion progress and history. Before generating a report, check that outstanding points and observations have been addressed.

## What to check before export

- Checklist template, delivery profile, frequency, and default time

## What to keep in mind

- A scheduled plan provides reminders; it does not start an inspection automatically.
