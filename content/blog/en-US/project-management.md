# Inspection projects: what it does in SiteReport

Field records become difficult to follow when project details, photos, and reports are kept separately.

## What this feature helps you do

- Create and manage inspection projects
- Track project status and inspection progress
- Keep project photos and reports together

## Where it fits in the workflow

- Create a new project
- Enter the site and project information
- Run inspections and review the project progress

## What to check before export

- Project status and project description

## What to keep in mind

- The available project fields and report outputs depend on the installed app version.
