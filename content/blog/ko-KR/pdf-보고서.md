# SiteReport에서 PDF 보고서 사용하는 방법

현장 관찰 내용을 일관된 보고서로 만들려면 수동 서식 작업이 필요할 수 있습니다.

## 사용 가능한 기능

- PDF 현장 보고서 생성
- 결과, 사진, 위치, 메모와 서명 포함
- 생성된 파일 확인

## 작업 절차

- 검사 기록 완료
- 보고서 옵션 선택
- 파일 생성 및 확인

## 확인할 설정

- 템플릿, 스타일, 형식과 서명

## 제한 사항

- 일부 스타일은 에디션 또는 이용 플랜에 따라 달라집니다.

## 보낼 파일을 직접 열어 확인하기

생성 전에 프로젝트, 결과, 사진, 메모와 서명을 검토하세요. PDF를 열어 가독성과 표시 상태를 확인합니다. 빠진 내용이 있으면 기록과 템플릿 설정을 확인하고 다시 생성하세요. 새 파일도 열어 확인한 뒤 공유할 때 해당 버전을 선택합니다. 파일 생성 성공과 상대방의 수신은 별도로 확인해야 합니다.
