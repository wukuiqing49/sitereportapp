# 내보내기와 전송: SiteReport 실무 가이드

완료된 보고서는 고객과 공유하거나 프로젝트 저장소로 보내야 하는 경우가 많습니다.

## 사용 가능한 기능

- PDF, 이미지와 ZIP 내보내기
- 기기에서 파일 공유
- 설정한 프로토콜로 전송

## 작업 절차

- 보고서와 파일 선택
- 공유 또는 전송 선택
- 상태 확인 또는 패키지 공유

## 확인할 설정

- 형식, 서명, 프로토콜, 서버와 경로

## 제한 사항

- 전송에는 설정된 대상과 네트워크 연결이 필요합니다.

## 전송 전에 저장 위치 확인하기

로컬 보고서를 검토하고 사용 가능한 PDF, 이미지, ZIP 중 형식을 선택하세요. 서버 전송은 관리자에게 프로토콜, 주소, 계정, 대상 경로를 확인해야 합니다. FTP, FTPS, SFTP, WebDAV, SMB/NAS는 서로 대체할 수 없습니다. 폴더를 볼 수 있어도 쓰기 권한이 있다는 뜻은 아닙니다. 확인되지 않은 위치를 시험할 때는 고객 정보가 없는 파일을 사용하세요.

## 수신 확인과 오류 점검

전송 후에는 상태를 확인하고 대상 위치의 복사본을 여세요. 공유 앱으로 전달했다고 고객 수신까지 확인된 것은 아닙니다. 실패하면 로컬 파일, 네트워크, 설정을 확인하세요. 재시도 전에 기존 복사본을 확인하고 자동 재개나 중복 제거를 가정하지 마세요. 지원 요청에는 암호를 제외한 오류 메시지를 전달합니다.
