# 검사 프로젝트: SiteReport 실무 가이드

프로젝트 정보, 사진과 보고서가 흩어져 있으면 현장 기록을 추적하기 어렵습니다.

## 사용 가능한 기능

- 검사 프로젝트 생성 및 관리
- 상태와 진행률 확인
- 프로젝트 사진과 보고서 보관

## 작업 절차

- 프로젝트 생성
- 현장 정보 입력
- 검사를 실행하고 진행률 확인

## 확인할 설정

- 프로젝트 상태와 설명

## 제한 사항

- 사용 가능한 항목은 설치된 버전에 따라 달라집니다.

## 프로젝트와 개별 방문 구분하기

프로젝트 이름에 현장이나 작업 구역을 포함하고 고객과 위치 정보를 기록하세요. 재방문할 때는 기존 프로젝트를 확인하여 이력이 흩어지지 않게 합니다. 현장을 떠나기 전에 진행 상황을 점검 기록, 사진, 보고서와 대조하세요. 프로젝트 상태만으로는 미해결 문제를 알 수 없습니다. 이번 방문에 해당하는 보고서를 선택했는지 확인하세요.
