# How to use 검사 체크리스트 in SiteReport

방문마다 다른 검사를 사용하면 반복 검사를 비교하기 어렵습니다.

## What this feature helps you do

- 재사용 가능한 검사 계획 생성
- 템플릿과 검사 지점 선택
- 검사를 재개하고 실행 이력 확인

## Where it fits in the workflow

- 계획 생성 또는 선택
- 템플릿과 전송 설정 선택
- 검사를 실행하고 각 지점 완료

## What to check before export

- 템플릿, 전송, 빈도와 기본 시간

## What to keep in mind

- 알림은 검사를 자동으로 시작하지 않습니다.
