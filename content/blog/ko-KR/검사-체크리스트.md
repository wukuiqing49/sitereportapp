# SiteReport에서 검사 체크리스트 사용하는 방법

방문마다 다른 검사를 사용하면 반복 검사를 비교하기 어렵습니다.

## 사용 가능한 기능

- 재사용 가능한 검사 계획 생성
- 템플릿과 검사 지점 선택
- 검사를 재개하고 실행 이력 확인

## 작업 절차

- 계획 생성 또는 선택
- 템플릿과 전송 설정 선택
- 검사를 실행하고 각 지점 완료

## 확인할 설정

- 템플릿, 전송, 빈도와 기본 시간

## 제한 사항

- 알림은 검사를 자동으로 시작하지 않습니다.

## 반복 점검을 비교하기 쉽게 만들기

처음 실행하기 전에 각 점검 항목의 위치와 대상을 정하세요. 범위가 같으면 계획을 재사용하고 구역이나 목적이 바뀌면 항목을 검토합니다. 중단한 점검을 계속하기 전에 진행 상황과 이력을 확인하세요. 알림은 점검 완료의 증거가 아닙니다. 보고서를 만들기 전에 미완료 항목을 확인하세요.
