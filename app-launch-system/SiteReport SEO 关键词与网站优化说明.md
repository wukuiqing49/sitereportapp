# SiteReport SEO 关键词与网站优化说明

SiteReport 的 SEO 核心定位调整为：

**Site Inspection App**

不要以品牌词 `SiteReport` 作为主要 SEO 关键词。品牌名称继续保留，但搜索引擎需要明确理解 SiteReport 是一款用于现场检查、检查清单、照片证据和检查报告生成的 Android 应用。

## 核心关键词

首页主要关键词：

**site inspection app**

重要辅助关键词：

- field inspection app
- inspection report app
- inspection checklist app
- site inspection report
- field inspection software

Google Keyword Planner 数据：

- site inspection app：100–1000/月
- field inspection app：100–1000/月
- property inspection app：100–1000/月
- site inspection report：100–1000/月
- inspection checklist：1000–1万/月

首页应该重点建立：

**SiteReport → Site Inspection App → Field Inspection → Inspection Checklist → Inspection Report**

的主题关系。

## Construction Inspection

这是重要的商业搜索方向，建议建立独立落地页。

主要关键词：

**construction inspection software**

相关关键词：

- construction inspection app
- construction site inspection app
- construction site inspection software
- construction site inspection report
- construction field report app
- construction inspection checklist
- construction site visit checklist
- construction site visit report

其中：

- construction inspection software：100–1000/月
- construction field report app：10–100/月，但广告出价较高
- construction safety inspection software：100–1000/月

不要为了 SEO 声称 SiteReport 拥有实际不存在的安全审计、法规认证或合规功能。

相关关键词：

- property inspection software
- mobile property inspection software
- inspection software for property managers
- property management inspection app
- property inspection report app
- property inspection checklist app
- property condition report app
- property condition report software

其中：

- property inspection app：100–1000/月
- property inspection software：100–1000/月
- mobile property inspection software：100–1000/月
- inspection software for property managers：100–1000/月

Property Inspection 是值得重点建设的商业搜索方向。

## Inspection Checklist

主要关键词：

**inspection checklist**

Google Keyword Planner 搜索量约：

**1000–1万/月**

相关关键词：

- inspection check list
- construction inspection checklist
- building inspection checklist
- construction site visit checklist
- property inspection checklist
- inspection check sheet

这个关键词搜索量较大，但搜索意图偏信息型。

不要把 `inspection checklist` 强行作为首页唯一核心关键词。

应该通过 Checklist 功能页、教程页、模板页等获得自然搜索流量，再将用户引导到 SiteReport App。

## SEO 执行原则

每个页面只确定：

**1 个主要关键词 + 3～5 个高度相关辅助关键词**

主要关键词自然出现在：

- Title
- Meta Description
- H1
- 部分 H2
- 首屏正文
- 正文
- 内部链接 Anchor Text
- 合适的图片 ALT

禁止关键词堆砌。

不要为了搜索量追逐与产品关系较弱的泛关键词，例如：

- building report
- report app
- inspection list

优先选择具有明确 App、Software、Inspection、Checklist、Report 搜索意图的关键词。

最终 SEO 主题关系：

**SiteReport → Site Inspection App → Field Inspection → Construction Inspection → Property Inspection → Inspection Checklist → Inspection Report**
