# SiteReport answer brief (en-US)

## Inspection projects

Field records become difficult to follow when project details, photos, and reports are kept separately.

### Can a project keep inspection reports together?

The project workflow includes project information, inspection progress, photos, and generated reports.

## Inspection checklist app

Repeated inspections are harder to compare when each field visit follows a different set of checks.

### Can an inspection plan be reused?

Yes. The app provides reusable inspection plans and checklist templates for repeated field work.

## Photo evidence and location records

A photo without its inspection context is difficult to use as evidence later.

### Can photos be linked to an inspection item?

Yes. The photo workflow associates captured evidence with the current inspection record and item.

## Field notes and sign-off

Inspection findings and sign-off details can be lost when they are recorded outside the report workflow.

### Can sign-off information appear in the report?

The report workflow supports signature profiles and writes signature information into generated report files.

## Inspection report app

Turning field observations into a consistent report can take significant manual formatting work.

### What can a generated field report contain?

The report can include project information, checklist results, inspection photos, location records, time records, notes, and signatures.

## Export and server delivery

Completed reports often need to be shared with clients or delivered to an existing project storage system.

### Which server delivery protocols are supported?

The project includes delivery support for FTP, FTPS, SFTP, WebDAV, and SMB/NAS configurations.
