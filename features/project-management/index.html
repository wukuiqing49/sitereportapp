Verified feature

Inspection projects

Create projects and keep site information, progress, photos, and reports together.

The problem it solves: Field records become difficult to follow when project details, photos, and reports are kept separately.

What you can do

  • Create and manage inspection projects
  • Track project status and inspection progress
  • Keep project photos and reports together

Available options

  • Project status and project description

Supported inputs

  • Project name, location, client information, and inspection notes

Outputs

  • An organized project record with progress and report history

Workflow

  1. Create a new project
  2. Enter the site and project information
  3. Run inspections and review the project progress

Limitations

  • The available project fields and report outputs depend on the installed app version.

Common questions

Can a project keep inspection reports together?

The project workflow includes project information, inspection progress, photos, and generated reports.
