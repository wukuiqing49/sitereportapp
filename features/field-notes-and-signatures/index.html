Verified feature

Field notes and sign-off

Record findings, corrective notes, and signature profiles as part of the inspection record.

The problem it solves: Inspection findings and sign-off details can be lost when they are recorded outside the report workflow.

What you can do

  • Record inspection results, issues, and recommendations
  • Manage signature profiles for field roles
  • Include notes and sign-off information in generated reports

Available options

  • Inspector, safety officer, supervisor, and company signature details

Supported inputs

  • Inspection notes, issue descriptions, recommendations, and signature details

Outputs

  • A documented inspection record with sign-off information

Workflow

  1. Open the relevant inspection item
  2. Record findings and corrective recommendations
  3. Add or select sign-off details before report generation

Limitations

  • The available signature fields and report presentation depend on the selected report template.

Common questions

Can sign-off information appear in the report?

The report workflow supports signature profiles and writes signature information into generated report files.
