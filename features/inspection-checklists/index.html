Inspection checklists

Use reusable inspection plans and checklist templates to standardize field work.

The problem it solves: Repeated inspections are harder to compare when each field visit follows a different set of checks.

What you can do

  • Create reusable inspection plans
  • Choose checklist templates and define inspection points
  • Resume an in-progress inspection and review run history

Available options

  • Checklist template, delivery profile, frequency, and default time

Supported inputs

  • Checklist items, inspection plan name, location, and schedule settings

Outputs

  • A repeatable inspection task with completion progress

Workflow

  1. Create or select an inspection plan
  2. Choose the checklist template and delivery settings
  3. Run the inspection and complete each inspection point

Limitations

  • A scheduled plan provides reminders; it does not start an inspection automatically.

Common questions

Can an inspection plan be reused?

Yes. The app provides reusable inspection plans and checklist templates for repeated field work.
