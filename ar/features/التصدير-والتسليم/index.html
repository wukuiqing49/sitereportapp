Verified feature

التصدير والتسليم

صدّر الملفات وأرسلها إلى خادم تم إعداده.

The problem it solves: تحتاج التقارير المكتملة غالباً إلى مشاركتها أو إرسالها إلى مساحة تخزين المشروع.

What you can do

  • تصدير PDF والصور وZIP
  • مشاركة الملفات من الجهاز
  • الإرسال عبر البروتوكولات التي تم إعدادها

Available options

  • الصيغة والتوقيعات والبروتوكول والخادم والمسار

Supported inputs

  • الملفات المنشأة وملف التسليم

Outputs

  • ملفات قابلة للمشاركة أو نتيجة الإرسال

Workflow

  1. أنشئ التقرير واختر الملفات
  2. اختر المشاركة أو التسليم
  3. راجع الحالة أو شارك الحزمة

Limitations

  • يتطلب التسليم وجهة معدة واتصالاً مناسباً بالشبكة.
