Verified feature

قوائم فحص

استخدم خططاً وقوالب قابلة لإعادة الاستخدام لتوحيد العمل.

The problem it solves: يصعب مقارنة الفحوصات المتكررة عندما تستخدم كل زيارة عناصر مختلفة.

What you can do

  • إنشاء خطط فحص قابلة لإعادة الاستخدام
  • اختيار القوالب ونقاط الفحص
  • استئناف الفحص ومراجعة السجل

Available options

  • القالب والتسليم والتكرار والوقت

Supported inputs

  • العناصر واسم الخطة والموقع والجدولة

Outputs

  • مهمة فحص متكررة مع تقدم

Workflow

  1. أنشئ خطة أو اخترها
  2. اختر القالب وإعدادات التسليم
  3. نفّذ الفحص وأكمل كل نقطة

Limitations

  • لا تبدأ التذكيرات الفحص تلقائياً.
