Verified feature

الصور وسجلات الموقع

اربط الصور بالعناصر وسجّل الملاحظات والوقت والموقع عند توفرها.

The problem it solves: يصعب استخدام صورة بلا سياق الفحص كدليل لاحقاً.

What you can do

  • التقاط صورة واحدة أو عدة صور
  • ربط الصور بسجل الفحص
  • تسجيل الموقع ووقت الالتقاط عند توفرهما

Available options

  • مصدر الصورة وعنصر الفحص والتعليق الظاهر

Supported inputs

  • الصور والملاحظات وإذن الموقع

Outputs

  • أدلة صور منظمة

Workflow

  1. افتح عنصر الفحص
  2. التقط صورة الدليل أو اخترها
  3. راجع الصورة وتابع

Limitations

  • تعتمد بيانات الموقع على الجهاز والأذونات.

Common questions

هل يمكن ربط الصور بعنصر فحص؟

نعم، يربط سير الصور الدليل بسجل الفحص والعنصر الحاليين.
