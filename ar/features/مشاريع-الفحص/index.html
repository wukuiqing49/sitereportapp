مشاريع الفحص

اجمع معلومات الموقع والتقدم والصور والتقارير في مكان واحد.

The problem it solves: يصعب تتبع السجلات عندما تكون بيانات المشروع والصور والتقارير منفصلة.

What you can do

  • إنشاء وإدارة مشاريع الفحص
  • تتبع الحالة والتقدم
  • حفظ صور المشروع وتقاريره معاً

Available options

  • حالة المشروع ووصفه

Supported inputs

  • الاسم والموقع وبيانات العميل والملاحظات

Outputs

  • سجل مشروع منظم مع التقدم والسجل السابق

Workflow

  1. أنشئ مشروعاً
  2. أدخل معلومات الموقع
  3. نفّذ الفحوصات وراجع التقدم

Limitations

  • تعتمد الحقول المتاحة على إصدار التطبيق المثبت.
